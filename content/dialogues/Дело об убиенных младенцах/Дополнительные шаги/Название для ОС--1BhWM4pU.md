**ВОПРОС**

Формулировка 1

Ведущий:

Согласны ли вы называть:

1) <особым статусом> – положение, когда то, что оправданно для вас, НЕ оправданно для другого;

2) <равным статусом> – положение, когда то, что оправданно для вас, оправданно и для другого?

P.S.: если НЕ согласны, то предложите свои краткие названия для <положения, когда то, что оправданно для вас, НЕ оправданно для другого> и для <положения, когда то, что оправданно для вас, оправданно и для другого>.

Формулировка 2 (если сначала оправдывал других)

Значит, вы не оправдаете других за совершение заказа.

Согласны ли вы называть:

1) <особым статусом> – положение, когда то, что оправданно для вас, НЕ оправданно для другого;

2) <равным статусом> – положение, когда то, что оправданно для вас, оправданно и для другого?

P.S.: если НЕ согласны, то предложите свои краткие названия для <положения, когда то, что оправданно для вас, НЕ оправданно для другого> и для <положения, когда то, что оправданно для вас, оправданно и для другого>.

**Ответы**

Вариант 1

[Да, согласен ](%D0%9A%D0%B0%D0%BA%20%D0%B2%D0%BE%D0%B7%D0%BD%D0%B8%D0%BA%20%D0%9E%D0%A1--1i9HQdsU.md)

Нет, не согласен
